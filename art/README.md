# Original artwork

**Lucas Marques, from Shiva**

This directory contains the original visual catalog and concept archive used
to develop The Free Game, including building and character sheets, landscapes,
visual specifications and available prompts. Original artwork is CC BY 4.0;
see ../LICENSE-ASSETS.md. Documentation is MIT.

Some sheets still show working names from the early concept stage. They are
historical design material. They include future ideas such as military units;
the current civilian beta does not implement every depicted feature.

The playable game's current textures, previews and mesh resources are in
`game/assets/`; its procedural 3D model code is in `game/presentation/`.
